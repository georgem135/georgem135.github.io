# Vhelaphi George Maluleke | Technology Portfolio

A responsive personal portfolio created for graduate technology applications. It presents practical Power BI work, web foundations, professional development and contact links in a clear, honest structure.

## Built with

- Semantic HTML5
- Modern responsive CSS
- Lightweight JavaScript
- GitHub Pages-compatible static hosting

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy to GitHub Pages

1. Create or open the repository named `georgem135.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for deployment and open `https://georgem135.github.io/`.
